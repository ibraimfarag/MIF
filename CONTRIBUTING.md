# Contributing to MI CS

We welcome contributions from the community!

## Guidelines

1. All code must be in English.
2. Follow the project architecture: UI never touches OS APIs directly.
3. Ensure no `unwrap()` in Rust production code.
4. All changes must pass `cargo clippy` and `flutter analyze`.

## Process

- Submit a PR with a clear description.
- Ensure you include tests for new collectors.
